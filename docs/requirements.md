# pr1.xlsx

## Лист1

### Роли и права доступа

| Роль | Как попадает в систему | Что может |
| Гость | Открыл сайт | Регистрация, вход |
| Клиент | Входит через авторизацию | Оставляет заявки, видит заявки и их статусы |
| Администратор | Вошёл как adminka / password | Видит все заявки, может менять статус и цену |

### Страницы сайта

| № | Страница (файл) | Кто видит | Что на ней |
| 1 | reg.php | Гость | Форма: логин, пароль, ФИО, телефон, email |
| 2 | log.php | Гость | Форма: логин, пароль, сообщение "неверный логин или пароль" |
| 3 | orders.php | Клиент | Список своих заявок со статусами, кнопка "Новая заявка" |
| 4 | order_new.php | Клиент | Форма заявки |
| 5 | admin.php | Админ | Таблица всех заявок, смена статуса, поле "причина отмены" |
| 6 | logout.php | Клиент, админ | Выход (страницы нет, только действие и редирект) |

### Правила валидации полей

| Поле | Правило из ТЗ | Где проверяем |
| Логин | Уникальный, > 6 символов | Сервер (уникальность), клиент и сервер (длина) |
| ФИО | Кириллица и пробелы | Регулярное выражение |
| Телефон | 8 (ХХХ)-ХХХ-ХХ-ХХ | Регулярное выражение / маска |
| Email | Формат email | type="email" + сервер |
| Статус | Диагностика, В ремонте, Готов к выдаче, Отклонено | Справочник в БД |
| Причина отмены | Обязательна при "отмене" | Сервер |
